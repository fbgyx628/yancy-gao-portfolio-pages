01

项目背景 / Context

肌研项目以水感、透亮和玻尿酸科技作为视觉核心，目标是让补水品类从常规清爽画面中跳出，建立更容易被记住的水润符号。

Background

补水品类竞争激烈，消费者容易把大量蓝白水感画面混为一谈。 项目需要在保持肌研清透品牌感的同时，把精简养肤、水润净透、玻尿酸功效转化为更明确的视觉记忆点。

Challenge

补水品类不是缺画面，而是缺记忆点。关键是把水润、清透和玻尿酸结构变成可复用的视觉语言。

Goal

建立以水润为核心的统一视觉基因。

02

视觉策略 / Visual Strategy

以极润蓝、流动水波和透明质地构成画面基底，把高保湿、透亮和玻尿酸补水能力转化为直接可感知的产品体验。

核心视觉符号 / Core Symbols

水润基因透明玻尿酸气泡蓝白清透画面水波与光泽产品瓶身露出

色彩 / 材质 / 构图策略

高明度蓝白水面反射透明材质轻量信息层级

03

视觉系统 / Visual System

  • 肌研概念视觉开发主视觉。
  • 以水润为基因承接三大产品卖点。
  • 围绕 4 重玻尿酸、天生水光和水润透亮建立系列画面。

04

多场景延展 / Extension

产品卖点可拆分为不同画面模块，用于详情页、电商首屏和社媒传播。

统一的蓝白水感资产让品牌在补水赛道中保持清晰且轻盈的识别。

05

项目价值 / Result & Value

把补水产品的功能点转化为更有记忆度的视觉资产。
保持肌研清透、干净、可信的品牌语气。
建立适合多平台延展的水感视觉系统。
