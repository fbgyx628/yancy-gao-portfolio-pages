01

项目背景 / Context

成分图鉴把抽象功效和原料质感转化为具体画面：液滴、油感、红色能量、金色质地与透明结构共同构成可用于产品和内容传播的图像资产。

Background

美妆与个护产品常常需要解释复杂成分，但直接讲科学容易枯燥。 项目通过材质、液体、光泽和色彩，把成分从信息点转化为更可感知的视觉资产。

Challenge

如何让成分不只是文字卖点，而成为能够支撑详情页、社媒和产品传播的视觉语言？

Goal

为不同成分建立清晰的质地和情绪表达。

02

视觉策略 / Visual Strategy

把成分想象成具有性格的材料：有的锋利、有的柔和、有的浓郁、有的清透。通过光线和液体结构让这些差异可视化。

核心视觉符号 / Core Symbols

液滴红色能量金色质地透明包裹植物与花朵成分

色彩 / 材质 / 构图策略

微距质感高光控制液体折射成分色彩编码

03

视觉系统 / Visual System

  • 成分图鉴章节建立项目方法。
  • Beauty Ingredients 以红色、金色、粉色液体表现成分能量。
  • Texture 与 Ingredients 页面沉淀为可复用素材库。

04

多场景延展 / Extension

成分视觉可作为详情页解释图、社媒科普视觉和新品 KV 背景资产。

不同质地资产共同构成产品内容传播中的科学美感。

05

项目价值 / Result & Value

提升成分信息的可读性与吸引力。
让抽象功效拥有更强的视觉记忆点。
为多产品线提供可复用的材质图像资产。
