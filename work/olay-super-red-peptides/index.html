01

项目背景 / Context

这个项目虽然不在本次完整 PDF 中，但仍保留为网页独立案例。它围绕 OLAY 第 4 代超红瓶面霜升级，把胜肽科学、红色能量与高端产品资产整合到一个强记忆符号中。

Background

红瓶系列已有明确品牌资产，需要在保留红色识别的同时，为第 4 代超红瓶面霜建立更高端、更科学的新一代视觉表达。 核心目标是让多重胜肽、抗老能量与器皿形态成为可持续延展的视觉资产。

Challenge

红色抗老视觉容易变得吵闹或促销化，需要在能量感和高级感之间取得平衡。

Goal

打造红色多重胜肽器皿作为 Campaign 核心记忆符号。

02

视觉策略 / Visual Strategy

将红色能量收束进透明器皿结构中，用精准材质、光点与流动感表现胜肽活性被科学控制、被高端容器承载的状态。

核心视觉符号 / Core Symbols

红色多重胜肽器皿能量胶囊红金光迹高端红瓶资产

色彩 / 材质 / 构图策略

控制红色饱和度透明器皿反射红金对比清晰功效层级

03

视觉系统 / Visual System

  • 核心符号：红色多重胜肽器皿。
  • 产品、胜肽科学与高端光影共同构成视觉升级。

04

多场景延展 / Extension

红色器皿可作为放大特写、横向延展和背景视觉资产使用。

从核心符号到详情页与电商资产，红色胜肽视觉让产品升级拥有清晰的识别锚点。

05

项目价值 / Result & Value

强化超红瓶系列的高端抗老感知。
为 Campaign 提供清晰可记忆的核心符号。
统一功效科学与电商转化资产。
