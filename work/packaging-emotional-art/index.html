01

项目背景 / Context

这一组作品关注包装、产品详情页和家居护理视觉的情绪表达。包装不只是信息容器，也可以成为消费者每天看见、触摸、使用的审美资产。

Background

日用产品需要从功能型包装中跳出，建立更柔和、更有生活方式感的视觉识别。 包装和详情页都需要在远看时有系列识别，近看时有细节质感，并适配不同销售触点。

Challenge

如何在不牺牲产品信息清晰度的前提下，用插画、材质与色彩让日用产品更有记忆点？

Goal

建立植物插画、柔和色彩和材质细节的包装语言。

02

视觉策略 / Visual Strategy

以插画、空间留白、低饱和色彩和轻量信息层级弱化功能产品的工具感，让包装像一件可以进入家居场景的日常艺术品。

核心视觉符号 / Core Symbols

植物线稿柔和蓝绿色调陶瓷艺术瓶家居护理图案空间与排版美学

色彩 / 材质 / 构图策略

低饱和色彩细节插画平衡留白系列化产品陈列电商视觉断点

03

视觉系统 / Visual System

  • 包装作为品牌情绪与生活场景的第一触点。
  • 陶瓷艺术瓶、家居护理包装、插画包装和详情页形成多类型案例。
  • 通过色彩、插画元素和空间关系建立系列化识别。

04

多场景延展 / Extension

插画语言可以从标签延伸到大面积背景与海报版式，形成更完整的品牌视觉世界。

包装视觉通过产品系列、插画细节与柔和色彩建立稳定的日常审美触点。

05

项目价值 / Result & Value

提升日用产品的货架审美与系列识别。
让包装转化为可持续传播的视觉资产。
建立商业清晰度与艺术质感之间的平衡。
