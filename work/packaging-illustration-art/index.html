01

项目背景 / Context

这一组作品关注视觉工艺与多维延展。包装不只是信息容器，也可以成为消费者每天看见、触摸、使用的审美资产。

Background

日用产品需要从功能型包装中跳出，建立更柔和、更有生活方式感的视觉识别。 包装插画需要在远看时有系列识别，近看时有细节质感，并适配不同销售触点。

Challenge

如何在不牺牲产品信息清晰度的前提下，用插画、色彩与版式让日用产品更有记忆点？

Goal

建立植物插画与柔和色彩的包装语言。

02

视觉策略 / Visual Strategy

以植物线稿、浅水蓝绿与绘画式背景弱化功能产品的工具感，让包装像一件可以进入家居场景的日常艺术品。

核心视觉符号 / Core Symbols

植物线稿柔和蓝绿色调瓶身与标签轮廓生活方式画面

色彩 / 材质 / 构图策略

低饱和色彩细节插画平衡留白系列化产品陈列

03

视觉系统 / Visual System

  • 视觉工艺与多维延展。
  • 包装插画系统用于瓶身、标签、套装与产品家族展示。
  • 通过色彩与插画元素建立 SKU 差异，同时保持系列统一。

04

多场景延展 / Extension

插画语言可以从标签延伸到大面积背景与海报版式，形成更完整的品牌视觉世界。

包装视觉通过产品系列、插画细节与柔和色彩建立稳定的日常审美触点。

05

项目价值 / Result & Value

提升日用产品的货架审美与系列识别。
让包装转化为可持续传播的视觉资产。
建立商业清晰度与艺术质感之间的平衡。
