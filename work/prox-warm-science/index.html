01

项目背景 / Context

Warm Science 将实验室专业感和肌肤触感结合起来，让 ProX 的科学功效不再冰冷，而是具备温和、可信、可持续延展的品牌视觉语言。

Background

ProX 需要在同质化科学护肤竞品中建立更鲜明的专家形象，同时承接淡斑小白瓶 PI、水乳 NI 与多条产品线资产。 视觉需要贯穿新品 KV、详情页、全域电商规范、UED、终端 PVM 与线下发布会 Toolkit。

Challenge

如何打破线上冷冰冰的实验室视觉，让专业科学以更有温度的方式进入肌肤管理语境？

Goal

以 Warm Science 重构 ProX 实验室视觉系统与肌肤管理权威。

02

视觉策略 / Visual Strategy

以白色实验室秩序为骨架，叠加水膜、透明气泡、浅水绿和肌肤触感，让科学功效具备温和、清透和可亲近的情绪。

03

视觉系统 / Visual System

  • Warm Science 主视觉与挑战 / 解法框架。
  • 淡斑小白瓶 PI、水乳 NI 与 38 节节点的产品视觉统一。
  • 全域电商体系、信息设计秩序与新品二级页视觉。
  • 线下发布会 Toolkit 与跨渠道资产标准。

04

多场景延展 / Extension

视觉从详情页延展到全域电商、UED、PVM 与线下发布会 Toolkit，保证不同业务触点拥有一致的科学温度。

同系列产品根据 TA 心智做差异化表达，在温和绿色系统中保留清晰的信息层级和购买路径。

05

项目价值 / Result & Value

以 Warm Science 重塑 ProX 肌肤管理专家心智。
拔高 OLAY / ProX 全域视觉资产标准。
建立从新品上市到发布会 Toolkit 的全链路视觉统筹能力。
